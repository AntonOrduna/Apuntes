UD3 – Práctica global de consultas SQL

Unidade didáctica: Consultas SQL

1. Obxectivo da práctica

Nesta práctica realizaranse diferentes consultas SQL sobre unha base de datos relacional, aplicando os conceptos traballados na unidade: selección e filtrado de rexistros, ordenación, funcións de agregación, agrupamentos, combinación de táboas, subconsultas, combinación de resultados e optimización de consultas.

O obxectivo é demostrar que se sabe formular consultas SQL adaptadas a diferentes necesidades de información e interpretar os resultados obtidos.

2. Preparación da base de datos

Utiliza a base de datos relacional empregada durante a unidade didáctica. Antes de comezar, comproba que existen as táboas necesarias, que as relacións entre elas están correctamente definidas e que conteñen datos suficientes para realizar todas as consultas.

Se é necesario, introduce novos rexistros para poder comprobar correctamente o funcionamento das consultas.

3. Desenvolvemento da práctica

Bloque 1. Consultas simples e filtrado

  1. Realiza consultas para mostrar diferentes columnas das táboas.
  2. Obtén resultados sen rexistros duplicados.
  3. Aplica condicións de filtrado utilizando operadores de comparación e lóxicos.
  4. Utiliza os operadores BETWEEN, IN e LIKE.
  5. Realiza consultas que permitan localizar valores nulos.
  6. Ordena os resultados e limita o número de rexistros devoltos.

Bloque 2. Funcións de agregación e agrupamentos

  1. Realiza consultas que utilicen as funcións COUNT, SUM, AVG, MIN e MAX.
  2. Agrupa os resultados utilizando GROUP BY.
  3. Aplica condicións sobre os grupos mediante HAVING.
  4. Combina agrupamentos con ordenación de resultados.

Bloque 3. Combinación de táboas

  1. Realiza consultas que combinen información de dúas táboas relacionadas mediante INNER JOIN.
  2. Combina información de tres ou máis táboas.
  3. Utiliza LEFT JOIN para mostrar tamén os rexistros que non teñen correspondencia na outra táboa.
  4. Utiliza RIGHT JOIN e compara os resultados cos obtidos mediante LEFT JOIN.
  5. Realiza consultas que permitan localizar rexistros sen relacións ou correspondencias noutras táboas.

Bloque 4. Subconsultas

  1. Realiza unha consulta que utilice unha subconsulta escalar.
  2. Utiliza unha subconsulta con IN ou NOT IN.
  3. Realiza unha consulta mediante EXISTS ou NOT EXISTS.
  4. Utiliza unha subconsulta que inclúa unha función de agregación.
  5. Realiza unha subconsulta correlacionada.

Bloque 5. Combinación de resultados

  1. Realiza dúas consultas compatibles e combina os seus resultados mediante UNION.
  2. Repite a operación utilizando UNION ALL.
  3. Compara os resultados e explica a diferenza entre ambos os operadores.
  4. Realiza unha consulta utilizando INTERSECT ou EXCEPT, se están dispoñibles na versión do SXBD utilizada.

Bloque 6. Optimización e análise de consultas

  1. Selecciona unha consulta que combine varias táboas ou utilice filtros.
  2. Analiza o seu plan de execución mediante EXPLAIN.
  3. Identifica a información máis relevante do plan: táboas consultadas, tipo de acceso, índices posibles, índice utilizado e número estimado de filas.
  4. Comproba se algún índice existente pode mellorar a consulta ou se sería conveniente crear un novo.
  5. Volver executar EXPLAIN e compara os resultados antes e despois dos cambios.

4. Entrega e documentación

A entrega consistirá nun único documento PDF que recolla o desenvolvemento completo da práctica. Non se entregarán ficheiros SQL independentes nin capturas soltas.

O documento deberá incluír:

  • Portada: nome e apelidos, curso e título da práctica.
  • Desenvolvemento: todos os bloques e exercicios realizados, identificados e ordenados.
  • Consultas SQL: o código completo de cada consulta.
  • Capturas de pantalla: imaxes nas que se poida comprobar a execución das consultas e os resultados obtidos.
  • Explicacións: unha breve descrición do obxectivo de cada consulta, dos operadores utilizados e da información que devolve.
  • Análise: comparación dos resultados cando se solicite e interpretación dos plans de execución no bloque de optimización.
Importante: As capturas deben permitir identificar claramente a consulta executada e o resultado obtido. Non é suficiente con incluír unicamente o código SQL ou unha imaxe dos resultados sen explicación.

5. Consideracións finais

  • Todas as consultas deben estar correctamente executadas e adaptadas á estrutura real da base de datos.
  • Os resultados deben ser coherentes cos datos almacenados.
  • As explicacións deben estar redactadas coas propias palabras, demostrando que se comprende o funcionamento das consultas.
  • O documento debe ter unha presentación ordenada, coidada e lexible.
  • O PDF debe entregarse nun único ficheiro co nome UD3_Apelidos_Nome.pdf.
