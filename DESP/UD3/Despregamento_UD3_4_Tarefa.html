Práctica final. Administración de servidores de aplicaciones

1. Objetivo de la práctica

El objetivo de esta práctica es desplegar y administrar una infraestructura web basada en Apache HTTP Server y Apache Tomcat, aplicando los conocimientos adquiridos durante la unidad didáctica.

Se trabajarán la instalación y configuración del servidor de aplicaciones, el despliegue de aplicaciones web, la autenticación y el control de acceso, la gestión de sesiones, la integración de servidores, la optimización, las pruebas de funcionamiento y la virtualización mediante contenedores.

La práctica debe permitir demostrar que se comprende el funcionamiento de los diferentes componentes de una infraestructura web y que se sabe configurar, desplegar, comprobar y documentar un servicio.

2. Descripción del trabajo

Apartado 1. Instalación y configuración de Tomcat

  • Instala y configura Apache Tomcat en el entorno de trabajo.
  • Comprueba el estado del servicio y su funcionamiento.
  • Identifica los principales directorios y archivos de configuración.
  • Analiza los puertos y parámetros básicos de ejecución.
  • Documenta las características principales de la instalación realizada.

Apartado 2. Despliegue de una aplicación web

  • Prepara una aplicación web Java para su despliegue.
  • Despliega la aplicación en Tomcat.
  • Comprueba el acceso a sus diferentes recursos.
  • Realiza una actualización o modificación del despliegue.
  • Comprueba el comportamiento de la aplicación después de los cambios.

Apartado 3. Autenticación y control de acceso

  • Configura un mecanismo de autenticación para proteger determinados recursos.
  • Define usuarios y roles con diferentes niveles de acceso.
  • Establece restricciones de acceso a los recursos de la aplicación.
  • Comprueba el comportamiento con usuarios autorizados y no autorizados.
  • Explica las medidas de seguridad aplicadas.

Apartado 4. Gestión de sesiones

  • Comprueba el funcionamiento de las sesiones HTTP de la aplicación.
  • Analiza el uso de cookies y del identificador de sesión.
  • Verifica el mantenimiento de la sesión durante la navegación.
  • Comprueba el comportamiento al cerrar sesión o cuando esta caduca.
  • Explica cómo se gestiona la información asociada a cada usuario.

Apartado 5. Integración de Apache HTTP Server y Tomcat

  • Instala o comprueba el funcionamiento de Apache HTTP Server.
  • Configura la integración entre Apache y Tomcat mediante un proxy inverso.
  • Habilita y utiliza los módulos necesarios.
  • Configura el acceso a la aplicación a través de Apache.
  • Comprueba que las peticiones llegan correctamente a Tomcat.
  • Explica las ventajas de utilizar esta arquitectura.

Apartado 6. Ajustes y optimización

  • Analiza los parámetros de memoria de la máquina virtual Java.
  • Realiza ajustes en la configuración de ejecución de Tomcat.
  • Revisa los parámetros del conector HTTP.
  • Comprueba el funcionamiento del servidor después de los cambios.
  • Justifica los ajustes realizados y explica su posible efecto sobre el rendimiento.

Apartado 7. Pruebas y análisis del funcionamiento

  • Realiza pruebas funcionales de la aplicación desplegada.
  • Comprueba su disponibilidad y analiza los códigos de respuesta HTTP.
  • Consulta los registros de Apache y Tomcat.
  • Realiza pruebas básicas de carga sobre la aplicación.
  • Analiza los tiempos de respuesta, las peticiones atendidas y los posibles errores.
  • Explica las conclusiones obtenidas a partir de las pruebas.

Apartado 8. Virtualización y contenedores

  • Prepara un entorno de despliegue mediante Docker.
  • Ejecuta un contenedor con Tomcat.
  • Despliega una aplicación web en el contenedor.
  • Define una infraestructura de varios servicios mediante Docker Compose.
  • Comprueba la comunicación entre los servicios y la persistencia de los datos cuando corresponda.
  • Explica las diferencias entre utilizar una máquina virtual y utilizar contenedores.

3. Documentación y entrega

La única entrega de la práctica será un documento PDF que recoja todo el proceso realizado.

El documento debe incluir, para cada apartado:

  • Descripción: explicación del objetivo y de lo que se pretende conseguir.
  • Procedimiento: descripción de los pasos realizados, las configuraciones aplicadas y los comandos utilizados cuando corresponda.
  • Capturas de pantalla: imágenes que permitan comprobar las instalaciones, configuraciones, despliegues y pruebas realizadas.
  • Resultados: explicación de los resultados obtenidos y de las comprobaciones efectuadas.
  • Conclusiones: valoración del funcionamiento y de los problemas encontrados, si los hubiera.
Importante: las capturas deben ser claras, legibles y estar relacionadas con las explicaciones del documento. No es suficiente con incluir imágenes sin indicar qué muestran o qué se pretende demostrar con ellas.

Estructura recomendada del PDF

  1. Portada con los datos del alumno y el título de la práctica.
  2. Introducción y descripción del entorno utilizado.
  3. Desarrollo de los ocho apartados de la práctica.
  4. Problemas encontrados y soluciones aplicadas.
  5. Conclusiones finales.

4. Requisitos de la entrega

  • Se entregará un único archivo en formato PDF.
  • El documento debe estar organizado y correctamente redactado.
  • Todas las configuraciones y pruebas deben estar explicadas.
  • Las capturas deben demostrar el trabajo realizado.
  • Se deben utilizar nombres y configuraciones coherentes en los ejemplos.
  • El trabajo debe reflejar la realización práctica de las tareas, no limitarse a una descripción teórica.
